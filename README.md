# Otel rezervasyon

Otel rezervasyonunu yöneten masaüstü uygulaması.

## Ne var

Ekranlar DevExpress bileşenleriyle kuruludur.

## Çalıştırma

Çözümü Visual Studio ile açıp başlangıç projesini çalıştırın. Veritabanı kullanan projelerde bağlantı dizesini kendi ortamınıza göre güncelleyin.

## Yığın

.NET Framework, Windows Forms, Entity Framework ve DevExpress.
